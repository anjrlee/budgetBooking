## Introduction

### project Overview

BirdieBudget is a soft, pastel-style budgeting and expense tracking web application designed to make financial management feel simple, emotional, and approachable.

Instead of using a traditional enterprise-style accounting interface, BirdieBudget uses a cute bird-themed UI with lightweight interactions, soft animations, and minimal friction input flow to encourage users to manage their spending comfortably.

The application supports:
- Budget group management
- Income and spending records
- Automatic budget distribution
- Financial statistics and reports
- Google Login authentication
- Multi-language support
